About Daterbase (English)

Daterbase is a personal, non-commercial productivity app that combines a decorated planner (calendar, to-dos, habit tracker, timer), commission (art request) management, a record journal (gallery, books, threads) and a budget book in one place. It runs as a web app and as a desktop app for Windows.

How Daterbase uses Google user data: Google sign-in is optional. Only after the user connects a Google account in Daterbase (web or desktop app) and grants access:

  • Google Calendar (calendar scope): shows events from the calendars the user picks in the app's timetable, and creates, updates or deletes the events the user makes in Daterbase on the user's own calendar (two-way sync).
  • Google Tasks (tasks scope): shows the user's Google Tasks in the app's to-do list and syncs tasks the user creates, edits, completes or deletes in Daterbase back to Google Tasks.
  • Google Drive (drive.file scope): saves the user's own planner data file in a "Daterbase" folder the app creates in the user's Drive, so it syncs between the user's devices. The app can only access files it created.

Data from Google APIs moves only between the user's device and the user's Google account. It is never sent to the developer or any third party, never sold, and not used for advertising, analytics or AI training. Daterbase's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

What you write in the app is stored only on your device, or, if you turn on sync, in a Supabase project or Google Drive folder you own. The developer cannot see it. See the Privacy Policy for the little the developer does receive (orders, anonymous usage stats, reports).
